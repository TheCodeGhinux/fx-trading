
## FXForage BACKEND API SERVICE

## Project setup

### Prerequisite
**Have NodeJS installed on your local machine**

### Running the project locally 

**1. Clone the Repo**
  ```bash
  git clone https://github.com/TheCodeGhinux/fx-trading
  ```

**2. Install the dependencies**
```bash
$ npm install
```

**3. Add environment variables, copy the env example and create a .env file in root of project**

**4. Compile and run the project**

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```
